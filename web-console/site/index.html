SSH 公钥从哪来

      

        

          在你自己（控制端）电脑上跑一次就能拿到公钥，把整行粘到左边：
        

        
ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_ed25519
type %USERPROFILE%\.ssh\id_ed25519.pub

        
        

          留空也能部署，只是控制端 ssh 进去时要输一次对方开机密码。

关于清除

      

        

          清除（橙）：移除开机任务 → 撤销你的公钥 → 删除安装目录。
          保留 Tailscale 入网，对方仍能连 tailnet，只是不再被本工具管理。


          彻底清除（红）：在上面基础上再退出 tailnet。对方会掉出你的网络，
          需要重新登录才能再连。


          两条都会在对方机器上把本工具删干净，不留开机任务、不留公钥、不留安装目录。
